## Qué he aprendido

### Python
- El ciclo del trabajo: escribir > guardar (Ctrl + S) > ejecutar. Si la pestaña tiene un punto blanco, el archivo no está guardado.
- input() SIEMPRE devuelve texto; para poder operar con numeros hay que convertirlo con int() o float().
- "def" solo define una funcion; NO SE EJECUTA hasta que se llama. Por eso "main()" va al final del archivo (o el nombre de la funcion definida).
- Parámetro VS Argumento. 
Parámetro = Es el hueco con nombre a definir la función.
Argumento = El valor real que le paso al llamarla. 
- "return" entrega un resultado a quien llamó la función; "print" solo lo muestra en pantalla.
- Separar tareas: "main" pregunta y muestra; las demás preguntas comprueban y devuelven.
- "if", "elif", "else"
"elif": con elif Python deja de comprobar EN CUANTO UNA condición se cumple.
- "and" une condiciones completas; "not" las niega; "in" comprueba si un texto contiene otro. 
- Herramientas nuevas: "len()", ".startswith()", ".lower", f-strings con ":.2f".
- Revisión senior: se puede devolver la condición directamente ("return CONDICION"), en vez de "if... True..else return False..."

## Linux y terminal

- SSH: abrir una terminal en otro ordenador ("ssh user@servidor.com -p puerto"). Lo que escribo después se ejecuta ahí.
- Comandos: "pwd", "cd" (y "cd .."), "ls" ("-A". "-l"), "cat", "file", "find", "cp" ("-r").
- Opciones ("-a") frente a argumentos (archivos o carpetas). 
- Nombres problemáticos: con guión ("./-"), con espacios (comillas o "\") y ocultos (empiezan por punto).
- "*" siginifica "TODO" pero se salta los ocultos; para incluirlos: ".*"
- "./" significa: "Esta carpeta" (ruta relativa); "/" al principio es la raíz del sistema (ruta absoluta).
- "find DÓNDE -CONDICIÓN": Primero la ruta, luego el filtro. "-size 1033c" = 1033 bytes.
- "ls -l" muestra permisos y tamaño; 
- Antes de hacer "cat", comprobar con "file" que el archivo es de texto.
