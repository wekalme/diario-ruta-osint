## Qué me ha costado

### Python / `crt.py`
- **Que lo que llega no siempre es JSON.** crt.sh me daba 502/504 y `respuesta.json()` explotaba con `JSONDecodeError`. Aprendí a imprimir `status_code` para saber qué había pasado, y a usar la URL que sí respondía.
- **`try` frente a `if`.** Al principio quise comprobar la conexión con un `if`. Una excepción no se comprueba con `if`: la línea explota antes de llegar. Regla: `try/except` para lo que explota (sin conexión, timeout) e `if` para lo que no explota (un 502 es una respuesta normal con un código malo).
- **Doble negación:** `not respuesta.status_code != 200` significa «ES 200», justo lo contrario de lo que quería. Y `not ==` no es sintaxis válida.
- **`datos` frente a `certificado` en el `for`:** `datos` es la lista entera; dentro del bucle se usa la ficha de cada vuelta (`certificado["name_value"]`), como `student["name"]`.
- **`"/n"` frente a `"\n"`:** el salto de línea lleva la barra invertida.
- **Dónde va cada comprobación:** fuera del `try`, cada una en su bloque y en orden (argumentos → conexión → código de estado → JSON). Cada bloque protege al siguiente.
- **`len(sys.argv) != 2`:** una sola condición cubre «falta el dominio» y «sobran argumentos».
- **Sorpresas en la salida de owasp.org:** salían correos de personas (certificados S/MIME) y otro dominio (`owasp.org.nz`). El programa necesita filtrar lo que **termina** en `.owasp.org`.

## Conceptos nuevos

- **Certificate Transparency:** cada certificado HTTPS queda en logs públicos con los dominios que protege. crt.sh guarda nombres que ya no existen: es un **registro histórico**; el DNS dice el **estado actual**.
- **Wildcard (`*.dominio`):** esconde subdominios en vez de revelarlos.
- **WHOIS/RDAP:** fecha de registro, registrador, privacidad del titular, bloqueo de transferencia, DNSSEC, **abuse contact** (para denunciar dominios que suplantan una marca) y hora de la consulta (anotarla siempre).
- **Términos de uso de WHOIS:** prohíben la consulta masiva automatizada. Límite a tener en cuenta en mi toolkit.
- **Pasivo / semipasivo / activo** en OSINT.
- **`requests`:** `requests.get(url, timeout=60)`, `respuesta.status_code`, `respuesta.json()`, `requests.RequestException`. Sin `timeout`, nunca salta el error por tiempo.
- **`sys.argv`** (lista con lo que escribo al ejecutar; `sys.argv[0]` es el nombre del script) y **`sys.exit("mensaje")`**.
- **`split("\n")`, `set()` (quita repetidos), `sorted()`, `startswith()` / `endswith()`, `.lower()`** (los dominios no distinguen mayúsculas).
- **Parámetro frente a argumento:** el parámetro es el hueco de la función; el argumento, el valor que le paso.
- **`stdout` y `stderr`:** dos salidas separadas; `2>` redirige solo los errores.
- **Rebase interactivo:** `pick` usa el commit; `squash` lo funde con el anterior. `squash` conserva la fecha del primer commit.
- **Stash:** «cajón» local para apartar cambios sin commitear. Mientras existe, sale en `git log --all`.
- **Organización del repo:** `diario/` es el registro semanal; `informes/` son los productos para el portfolio.

## Comandos nuevos

```bash
# --- Bandit / Linux ---
find / -user bandit7 -group bandit6 -size 33c 2>/dev/null   # buscar por propietario, grupo y tamaño (c = bytes) en todo el servidor
grep "millionth" data.txt          # líneas que contienen un texto
sort data.txt | uniq -u            # la única línea que no se repite (uniq solo compara líneas vecinas: hay que ordenar antes)
strings data.txt | grep "==="      # texto legible dentro de un binario, filtrado
man uniq                           # manual: flechas, /palabra, n, q
# Ctrl + C -> interrumpir · Ctrl + D -> fin de entrada · Ctrl + Z -> congela (fg lo recupera)

# --- DNS / OSINT ---
nslookup -type=NS owasp.org        # servidores DNS de un dominio (viene con Windows)
nslookup admin.owasp.org           # ¿sigue existiendo en DNS? (semipasivo)

# --- Archivos ---
mv viejo.md nuevo.md               # renombrar = mover al mismo sitio con otro nombre

# --- Python ---
python -m pip install requests     # instalar una librería
python crt.py owasp.org            # pasar un argumento al script

# --- Git ---
git stash                          # apartar cambios sin commitear
git stash pop                      # recuperarlos
git rebase -i HEAD~4               # reescribir los 4 últimos commits (pick / squash)
git rebase --continue / --abort    # seguir o cancelar un rebase
git config --global core.editor "code --wait"   # VS Code como editor de Git
git log --oneline --graph --all    # comprobar la historia
# Vim de emergencia: i (escribir) · Esc · :wq (guardar y salir) · :cq (salir cancelando)
```
